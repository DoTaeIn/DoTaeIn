# 🧠 Featured Project — Marco

<div align="center">

## Marco

### An AI that remembers knowledge, not just tokens.

**Knowledge Graph · Persistent Memory · Reasoning · Cognitive Architecture**

</div>

<br>

일반적인 AI가 제한된 **토큰 컨텍스트 안에서 정보를 유지하는 방식**을 넘어,

Marco는 지식을 **Knowledge Graph** 형태로 구성하고  
그 관계를 지속적으로 축적하는 AI 시스템을 목표로 합니다.

```text
Experience
    │
    ▼
 Knowledge
    │
    ├──── Entity
    ├──── Concept
    ├──── Relation
    └──── Memory
             │
             ▼
       Knowledge Graph
             │
             ▼
          Reasoning
```

대화에서 얻은 정보를 단순한 텍스트 기록으로 저장하는 것이 아니라,

**개체(Entity)**  
**개념(Concept)**  
**관계(Relation)**  
**경험(Experience)**

사이의 연결을 구조화합니다.

새로운 경험은 기존의 지식과 연결되고,  
그 연결은 이후의 기억과 판단에 다시 영향을 줍니다.

결국 목표는 단순히 대화를 이어가는 AI가 아니라,

> **시간이 지나도 자신이 배운 것을 구조적으로 축적하고  
> 그 지식을 바탕으로 다시 생각할 수 있는 AI.**

그리고 이 구조 위에서 Marco는  
감정, 인간관계, 가치관과 경험 또한 학습하며  
시간이 흐를수록 자신만의 기억과 인격을 형성합니다.
